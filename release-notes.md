**Nyx for Windows** — local-first, on-device AI copilot. No account, no cloud, no telemetry.

### Install
1. Download **Nyx-Setup.exe** below.
2. Run it. If Windows warns about an unknown publisher, click **More info → Run anyway**.
3. Open Nyx, pick a model that fits your PC, and start asking.

Windows 10/11 (64-bit) · ~120 MB installer · 1–5 GB per model (downloaded once, then fully offline).

_Nyx updates itself automatically on future releases._
